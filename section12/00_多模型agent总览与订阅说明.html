Claude Code 与 Codex 多模型 Agent 总览与订阅说明

学习目标

  • 了解 Claude Code 与 OpenAI Codex 是什么，以及它们在 VS Code 中的核心能力。
  • 掌握 Claude（Anthropic）与 Codex（OpenAI/ChatGPT）的官方订阅方案与价格。
  • 掌握”订阅套餐 / API Key / 第三方网关”三种接入模式的区别与选择方法。
  • 了解本节各章节的学习路径与前置依赖。

前置条件

  • 已安装 VS Code（参考 section1/02）。
  • 已了解 Agent 基础（参考 section9/00）。
  • 已了解 Copilot 基础（参考 section10/00）。
  • 具备基本的文件操作与 Markdown 编辑能力。

Claude Code 与 Codex 是什么

Claude Code 与 OpenAI Codex 是目前最主流的两类 Agent 化编程工具。与传统”逐行补全 + 对话问答”不同，它们可以在终端或 IDE 中自主完成多步骤任务：读取代码、搜索文件、执行命令、修改文件、运行测试、提交 PR 等。

本教程聚焦 VS Code 环境：两者都有官方 VS Code 扩展，也支持终端 CLI 工作流。

核心能力对比

对比项Claude Code（Anthropic）OpenAI Codex
开发商AnthropicOpenAI
默认模型Claude Opus / Sonnet 系列GPT-5.6 系列（Sol / Terra / Luna）
VS Code 支持官方扩展 + CLI（推荐扩展体验）官方扩展 + CLI（IDE 扩展 / Codex Cloud）
订阅入口Claude Pro / Max / Team / Enterprise随 ChatGPT 套餐（Plus / Pro 等），无独立订阅
独立 API有（Anthropic API，/v1/messages）有（OpenAI API，/v1/responses 等）
典型协议Anthropic 原生 Messages 协议Responses / Chat Completions
开源情况商业闭源CLI 开源，云服务闭源

与 Copilot 的关系

工具定位订阅来源
GitHub CopilotVS Code 内置 AI 助手，覆盖面广GitHub 订阅（见 section10/00）
Claude Code独立 Agent 工具，深度自主执行Claude 订阅或 Anthropic API
OpenAI Codex独立 Agent 工具，深度自主执行ChatGPT 订阅或 OpenAI API

三者可以在同一台 VS Code 中共存：Copilot 负责日常补全与对话，Claude Code / Codex 负责大型自主任务。

Claude 官方目前（2026 年 8 月）提供从免费到企业级的多档方案，价格可能随时间调整，以下为官网参考：

Claude 订阅要点（2026 年动态）

  • 2026-05-06 起：Anthropic 将各付费套餐的 Claude Code 5 小时限速翻倍，并取消高峰时段降速。
  • 2026-06-15 起：将”人机交互”与”自主 Agent 运行”分开计量。Claude Code 交互式会话沿用原有窗口/周限额；Agent SDK 项目、claude -p 无头运行、GitHub Actions 集成等，从新的月度 Agent SDK 信用额度 中扣除（Pro $20 / Max 5x $100 / Max 20x $200 / Team Premium $100 每座）。
  • 2026-04-21：曾有”Pro 移除 Claude Code”的 2% 小流量测试（约 12 小时），官方澄清现有用户不受影响。Pro 目前仍包含 Claude Code。

💡 选择建议：轻度尝试选 Pro（$20/月）；每天长时间跑 Agent 选 Max 5x（$100/月）；多任务并行、重度使用选 Max 20x（$200/月）；纯 API 开发场景按量付费更划算。

订阅方案：Codex（OpenAI）

Codex 没有独立的订阅套餐，其用量包含在所有 ChatGPT 套餐中。升级 ChatGPT 档位即解锁更多 Codex 用量：

个人方案

方案价格适用对象主要特性
Free$0/月试用少量 Codex 用量，适合尝鲜
Go$8/月轻量使用比 Free 更多用量，适合学生 / 偶尔使用
Plus$20/月个人开发者完整 Codex（CLI / IDE 扩展 / Cloud）；5 小时滚动窗口 + 每周上限（约 15–90 条消息/窗口，依模型）
Pro 5x$100/月重度用户5x Plus 用量（2026-04-09 新增；首发促销至 5/31 曾为 10x）
Pro 20x$200/月极限用户20x Plus 用量，适合全天候 Agent 运行

团队 / 企业方案

方案价格适用对象说明
Business约 $20/座/月（年付），$25/座/月（月付）团队共享工作区额度、管理控制、GitHub / Slack 集成
Enterprise / Edu联系销售大型组织共享额度池、无固定限速、SCIM / EKM、专属支持

Codex 订阅要点（2026 年动态）

  • 2026-04-02 起：Codex 用量从”按消息数”改为 与 API token 对齐的信用额度（约 $0.04/credit），在 5 小时滚动窗口 + 每周上限内计量。
  • 2026-04-09 起：原 $200 Pro 拆分为 Pro 5x（$100） 与 Pro 20x（$200），直接对标 Claude Max。
  • 2026-07-09 起：GPT-5.6（Sol / Terra / Luna）在 ChatGPT、Codex 与 API 全面可用，替代 5.5 系列。
  • API 按量计费参考：GPT-5.6-Luna 约 $1.00/百万输入 token、$6.00/百万输出 token（以官方定价页为准）。

💡 选择建议：偶尔使用选 Plus（$20/月）；把 Codex 作为日常主力选 Pro 5x（$100/月）；全天候并行 Agent 选 Pro 20x（$200/月）；团队用 Business，大型组织联系销售。

三种接入模式怎么选

接入模式典型场景需要什么成本模型
官方订阅日常使用、开箱即用Claude / ChatGPT 账号登录固定月费，有限额
API Key按量计费、自动化Anthropic / OpenAI 平台 API Key按 token 计费，无硬上限
第三方网关国内直连、多模型切换网关 Base URL + Key + 匹配的模型名网关定价，通常更便宜

三条总规则：

  1. 先看”客户端协议”，再看”模型名” —— 不是模型决定接口，而是客户端使用的协议决定接口。
  2. Base URL 与 Endpoint 分开理解 —— 大多数配置项要求填 Base URL（通常到 /v1 或域名根），不是完整接口路径。
  3. 排错顺序固定 —— 网络连通性 → 鉴权 → Endpoint → 请求体 Schema → 模型名。

如何查看当前订阅状态

Claude

  • 在 Claude Code 内输入 /status 或 /usage 查看当前会话额度与用量。
  • 网页端登录 claude.ai → 账户设置查看订阅档位。

Codex

  • 在 Codex CLI 或 VS Code 扩展中查看当前登录账号与套餐。
  • 网页端登录 chatgpt.com → 设置 → 订阅查看档位。
  • 在扩展中执行登录 / 鉴权命令可随时切换账号。
