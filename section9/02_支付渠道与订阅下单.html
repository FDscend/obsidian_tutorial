支付渠道与订阅下单

学习目标

  • 盘点国内用户订阅海外 AI 服务的六条可行路径与各自成本。
  • 掌握”海外信用卡 + 免税州地址""App Store 礼品卡""Google Play 银联卡""PayPal 国区账号”几条主流路径的操作要点。
  • 理解代充（session token）的原理与风险，学会判断一个价格是否合理。
  • 完成一次自己的订阅下单，并知道如何验证订阅是否生效。

前置条件

  • 已完成 01_账号注册与2fa配置（Google / ChatGPT 账号已就绪并开启 2FA）。
  • 手机可安装 App（iOS 或 Android），且有可用的支付方式。

支付渠道总览

以下为国内用户订阅 ChatGPT / Claude 等服务的常见路径（价格随时间、汇率、税费波动，数字为 2026-10 前后观察值，以结账页为准）：

路径需要什么月成本参考（Plus / Copilot 档）难度风险
海外信用卡直付海外发卡信用卡约 136￥（免税州）中低
海外信用卡 + 低价区同上 + 目标地区地址约 120￥中低
App Store 礼品卡（iOS）美区 Apple ID + 礼品卡视卡价浮动中低–中
Google Play（Android）Google Play + 新加坡区 + 银联卡约 150￥（含税）中低

优先顺序建议

海外信用卡 > 应用商店 / PayPal 官方渠道 > 第三方代充。官方渠道都是”动手麻烦但可控”，代充是”省事但把账号安全交了出去”。

路径一：海外信用卡直付（最干净）

为什么国内 Visa / Mastercard 常被拒

国内发行的双币信用卡在境外订阅场景下常被风控拒绝，原因通常是发卡地 + 账单地址 + 商户风控策略的组合，而不是卡本身余额不足。用海外发卡的信用卡（或合规的虚拟卡服务）通常一次通过。

操作步骤

  1. 准备一张海外发卡信用卡（实体卡或合规虚拟卡）。

  2. 打开 ChatGPT 订阅页 → 升级 Plus → 填写卡号、有效期、CVC。

  3. 账单地址选择美国免税州，例如：

    州说明
    Oregon无州销售税（常用）
    Delaware无州销售税（常用）
    Montana无州销售税
    New Hampshire无州销售税

    免税州可避免美国各州销售税；地址中的门牌号可与平台常用演示值一致，确保格式可被校验通过。

  4. 提交后确认扣款金额 = 标价（不额外加税）。

变体：追求低价区

有海外卡后，可以把账单地址换成订阅定价更低的国家/地区（例如菲律宾、日本等），实际支出约 120￥ 上下。注意：部分平台会核查使用地区一致性，跨区订阅存在被要求补差价或限制的风险，以服务条款为准。

路径二：App Store 礼品卡（iOS）

没有海外信用卡时，Apple 渠道是最常用的一条路：

  1. 准备美区 Apple ID：在 Apple 官网注册，地区选美国，地址填免税州（见上表）。
  2. 购买 App Store 礼品卡：通过支付宝渠道购买 Apple Gift Card（注意甄别渠道，拒绝来路不明的低价卡）。
  3. 兑换余额：App Store → 右上角头像 → 兑换充值卡或代码 → 输入卡号。
  4. 在 App 内订阅：手机安装 ChatGPT App（用已登录的账号），在 App 内点升级 → 跳转 Apple 支付 → 用余额扣款。

礼品卡的两个坑

一是黑卡：来路不正的礼品卡兑换后可能被 Apple 回收余额；二是地区匹配：美区 ID 只能用美区礼品卡，日区只能用日区卡，买前确认卡的区服。

路径三：Google Play（Android）

  1. 安装 Google Play：国产 Android 手机通常需自行安装 Google 服务框架与 Play 商店（详见手机厂商教程）。

  2. 把 Google 账号地区设为新加坡：Google Play → 设置 → 账号 → 国家/地区，选择新加坡。

    地区更改有冷却期

    Google Play 的国家/地区变更通常有等待期（一年一次）。操作前想清楚，避免把账号锁在无法支付的地区。

  3. 绑定银联卡：新加坡区支持绑定银联卡作为支付方式（部分其他地区虽然能绑，但无法用于订阅 ChatGPT）。

  4. 在 App 内订阅：ChatGPT App → 订阅 → 跳转 Google Play → 完成支付。

Google Play 路径走新加坡区时，显示价约为 138￥ 再叠加约 12￥ 税费，合计约 150￥，是三条约 136–150￥ 路径中单价最高但最省心的一条。

路径四：应用商店 + 国内信用卡

如果你有招行 Visa 等能被应用商店接受的国内信用卡，可以在 Apple / Google 商店中直接绑定该卡，然后把账号切到低价区下单——支付由商店代扣，绕开了网站端的发卡地风控。

这条路径的本质与路径二、三相同：让应用商店做”支付中介”，你只需要一张商店认可的卡。

路径五：PayPal（国区 + 银联卡）

GitHub Copilot 等服务的结账页支持 PayPal，而中国大陆区的 PayPal 账号可以绑定银联卡——于是一条既不打应用商店、也不需要海外卡的路径就通了：

  1. 注册 PayPal 国区账号：在 paypal.com 用手机号 / 邮箱注册，国家/地区选择中国。
  2. 绑定银联卡：进入”钱包 → 添加银行卡”，绑定银联信用卡（部分银行的借记卡也可），按提示完成验证。
  3. 在结账页选择 PayPal：以 GitHub Copilot 为例，进入订阅结账 → 支付方式选 PayPal → 跳转登录并确认付款。
  4. 确认订阅生效：回到服务方的账单页，核对订阅状态与续费日期。

适用范围与限制

  • PayPal 并非所有 AI 服务都支持：OpenAI / Anthropic 的网页订阅通常只收信用卡；Copilot 走 GitHub 的结账体系，是国区用户最容易走通的一家。
  • 实际扣款按 PayPal 的结算汇率与规则执行，金额可能与银行直付略有差异，以结账页为准。

关于 Copilot 的性价比

用 PayPal 付 Copilot 很方便，但要知道它的额度倍率处在同类方案的最低水平：Pro 档 $10 / 月对应 $15 AI 信用额度，约 1.5 倍。同样的预算如果换成聚合套餐或 Claude / ChatGPT 档位，“可用量”通常更大——对比见 03 的案例表与 section11/00。

路径六：第三方代充（先看风险再决定）

代充的常见流程是：你在第三方平台付款 → 平台要求你提供 ChatGPT 网页的会话信息（Session Token） → 平台用你的登录态在网页端完成下单。

Session Token 是什么

Session Token 是浏览器里的登录凭据。你登录 ChatGPT 后，浏览器就持有这串凭据；把 token 交出去，等于把账号在一段时间内的控制权交给对方——对方能看到的不仅是账号，还有你的全部聊天记录。

三条红线

  1. 任何要求提供密码、短信验证码的服务，直接放弃。
  2. 提供 Session Token 后应立即退出全部会话使其失效；但仍无法保证对方在有效期内未做其他操作。
  3. OpenAI 等平台的服务条款明确禁止共享账户凭据，代充本身可能构成条款违规，由此引发的封号难有申诉渠道。

代充的”便宜”从哪来

层级模式对你的实际风险
1正常代付（帮付官方订阅）低，但价格通常不便宜
2低价区套利违反平台地区规则，可能被追补
3共享账号 / 拆座位聊天记录、支付信息互相暴露
4黑号号池（盗号、接码号）随时被找回、封禁、二次售卖
5盗刷 / 拒付涉及欺诈，买家权益在清算时最先受损

价格怎么判断

  • 低于自行订阅的成本线（约 120￥）：要问”便宜的部分从哪来”，通常对应上表第 3 层及以上。
  • 高于约 150￥：没有必要——Google Play + 新加坡路径已是最省心方案，全流程可控且 0 额外风险。
  • 支持开发票、有公开商品页与客服、有订单查询的平台相对正规，但仍不等于无风险。

结论

代充不是”不能碰”，而是要把风险算进价格：省下的几十元，可能对应的是聊天记录暴露或掉权益。优先用前四条路径解决支付问题。

下单检查清单

订阅前：

  • 已确认所选平台的套餐档位与额度（对照 00 的术语表）。
  • 已确认是否支持自动续费、如何取消续费。
  • 支付路径与账号地区匹配（美区 ID 对美区卡 / 美区礼品卡）。

订阅后：

  • 在账号设置页确认订阅档位已生效（Plan / Subscription 页面）。
  • 检查扣款金额与预期一致（无额外税费、无误扣）。
  • 记下续费日期，避免忘记取消。
  • 若走代理：确认代理放行本地回调（127.0.0.1 / localhost），否则登录类操作可能失败。

常见问题

Q：一个账号可以多人共用吗？

平台条款通常禁止共享账号凭据。多人共用意味着聊天记录互相可见、登录环境互相污染，也是账号被封的常见原因。

Q：订阅后可以退款吗？

应用商店（Apple / Google）通常有各自的退款政策，网站直付则一般不支持退款。先按月买是最稳妥的策略。

Q：现在买 Plus 还是 Pro / Max？

先用最低档跑一个月，统计自己的真实用量（见 00 的估算流程），再决定升档。各档位具体价格见 section11/00 与 section13/00。

Q：为什么我在网页上支付总失败？

常见原因：发卡地风控、账单地址与卡不匹配、代理导致 IP 与地址不一致、浏览器插件干扰。依次排查；仍失败则换应用商店路径。

练习任务

  1. 对照总览表，写出你自己能走通的两条路径，并标出各自的月成本。
  2. 假设你选择 Google Play 路径，列出完整步骤（安装 → 改区 → 绑卡 → 下单）。
  3. 找一个第三方代充报价，用第八节的价格判断法分析：它处在第几层？你愿不愿意用这个价格换这个风险？
  4. 完成一次真实订阅（选择你能走通的最优路径），截图记录账号设置页中的订阅状态。

验收清单

  • 能说出六条支付路径各自需要什么、成本多少、风险如何。
  • 能解释国内信用卡被拒的常见原因，以及”免税州地址”的作用。
  • 能说清 Session Token 是什么，以及为什么不交给第三方。
  • 能用”成本线”判断一个代充报价是否合理。
  • 已完成一次订阅，并能独立验证订阅状态与续费日期。
