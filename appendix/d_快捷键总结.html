常用快捷键总结

VS Code 通用

快捷键功能
Ctrl+S保存文件
Ctrl+Z撤销
Ctrl+Y恢复（重做）
Ctrl+X剪切
Ctrl+C复制
Ctrl+V粘贴
Ctrl+F在当前文件中查找
Ctrl+H在当前文件中替换
Ctrl+Shift+F在全部文件中查找
Ctrl+P快速打开文件
Ctrl+`打开/关闭终端
Ctrl+B切换侧边栏
Ctrl+Shift+P打开命令面板
Ctrl+Shift+X打开扩展面板
Ctrl+Shift+U打开输出面板
Ctrl+K V打开侧边 Markdown 预览
Ctrl+Shift+V打开 Markdown 预览标签页
Ctrl+K Ctrl+T切换配色主题
Alt+Z切换自动换行 / 不换行
Alt+Shift + 鼠标点击多选行（列编辑）
Ctrl+/注释/取消注释当前行或选中的代码
Ctrl+D选中下一个相同的词
Ctrl+Shift+L选中所有相同的词

VS Code Git（源代码管理）

快捷键功能
Ctrl+Shift+G打开源代码管理面板
Ctrl+Enter提交更改（在提交信息输入框中）
Ctrl+Shift+P → Git: 拉取从远程拉取
Ctrl+Shift+P → Git: 推送推送到远程
Ctrl+Shift+P → Git: 切换到分支切换分支

Obsidian 通用

快捷键功能
Ctrl+P打开命令面板
Ctrl+E切换编辑/预览模式
Ctrl+N新建笔记
Ctrl+O快速打开笔记
Ctrl+S保存当前笔记
Ctrl+F在当前笔记中搜索
Ctrl+Shift+F在全部笔记中搜索
Ctrl+Click（或 Alt+Click）打开 WikiLink 链接
[[插入 WikiLink（自动补全）

Obsidian Canvas

快捷键功能
Ctrl + 鼠标拖拽 / 鼠标中键拖拽平移画布
Ctrl+滚轮 / 触控板双指缩放缩放画布
Ctrl+0适应画布大小
N创建空文本卡片
Delete / Backspace删除选中的卡片或连接线
Shift + 拖拽卡片保持水平/垂直对齐移动
Ctrl + 点击卡片多选卡片
Ctrl+F在当前 Canvas 中搜索文本（需 Advanced Canvas 插件）
Ctrl+Z撤销（Canvas 支持多步撤销）
Esc退出演示/翻页模式

Obsidian Bases

快捷键功能
Ctrl 或 Alt + 点击列头按该列排序
Ctrl + 点击已排序的列头切换升序/降序

GitHub Copilot

快捷键功能
Ctrl+I打开内联对话
Ctrl+Alt+I打开 Chat 面板
Tab接受当前代码补全建议
Ctrl+→逐词接受建议
Alt+[切换到上一个建议
Alt+]切换到下一个建议
Esc拒绝当前建议

常用终端命令

命令说明
git clone <url>克隆远程仓库
git status查看工作区状态
git add <文件>暂存文件
git commit -m "信息"提交更改
git push推送到远程
git pull从远程拉取
git branch列出分支
git checkout -b <分支名>创建并切换分支
git merge <分支名>合并分支
cd <目录>切换目录
ls / dir列出文件（Linux/macOS / Windows）
mkdir <目录>创建目录
